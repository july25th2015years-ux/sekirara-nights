# Sekirara Nights (セキララカード for adults 風 対話Webアプリ)

大人同士がベッドサイドやお酒の席で、普段なかなか話せない「性・身体・愛情・本音の願望」を、安心かつロマンチックに語り合うためのWebアプリケーションです。

---

## 🌟 主な特徴

- **Night Romantic テーマ**:
  - 深みのあるワインレッド、インディゴ、シャンパンゴールドを基調とした上質なビジュアル
  - スムーズな 3D カードフリップ（裏表めくり）アニメーション
- **段階的レベル制（全90枚のカードマスターデータ）**:
  - **Level 1（出会い & 恋愛観 / 25問）**: 第一印象やお互いのキュンとした瞬間などのアイスブレイク
  - **Level 2（親密さ & 関係性 / 25問）**: 感謝の気持ちや身体の好み、普段言えない本音に一歩踏み込む質問
  - **Level 3（性の本音 & 夜の過ごし方 / 25問）**: 夜の営みの本音、秘密の願望、試してみたいことなどのディープな対話
  - **アクションカード（スキンシップミッション / 15枚）**: 「10秒見つめ合う」「耳元で囁く」など、実践できるスキンシップカードがランダムに出現
- **安心のセーフティ機能 & 進行サポート**:
  - **パス（スキップ）機能**: 答えたくない質問はペナルティなくワンタップでスキップ可能
  - **ターン表示**: 「あなたから回答」「パートナーが回答」「2人で答える」を案内
  - **3つの約束（HOW TO PLAY）**: パス自由・本音を否定しない・2人だけの秘密
- **カスタマイズ & お気に入り**:
  - **オリジナルカード作成**: 2人だけの特別な質問やアクションを追加・編集可能（ブラウザの LocalStorage に保存）
  - **お気に入り機能**: 後でまた話したい質問を保存・閲覧可能
- **サイレント設計**:
  - 2人の会話の空気感や囁きを遮らない無音仕様

## 🛠️ 技術スタック

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** (Night Romantic カスタムテーマ)
- **Lucide React** (アイコン)
- **Canvas Confetti** (演出)

---

## 🚀 起動方法

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてご利用いただけます。

### 3. プロダクションビルド
```bash
npm run build
npm run preview
```
