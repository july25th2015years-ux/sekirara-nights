# Sekirara Nights (セキララカード for adults 風 対話Webアプリ)

恋人同士がベッドサイドやお酒の席で、普段なかなか話せない「性・身体・愛情・本音の願望」を、安心かつロマンチックに語り合い、より深く親密になるためのWebアプリケーションです。

---

## 🌟 主な特徴

- **全120問の大ボリューム（完全新規作成）**:
  - **Level 1（出会い & 恋愛心理 / 30問）**: 第一印象やお互いのキュンとした瞬間、テンポよく答えるYES/NO質問などのアイスブレイク
  - **Level 2（親密さ & 関係性 / 30問）**: 普段言えない感謝の気持ちや身体の好み、フェチ、触れ合いの本音
  - **Level 3（性の本音 & 夜の過ごし方 / 30問）**: 夜の営みで一番気持ちいい瞬間、秘密の願望、試してみたいシチュエーションなどのディープな対話
  - **スキンシップ（ドキドキ実践ミッション / 30問）**: 「10秒見つめ合う」「耳元で囁く」「ハグ」「キス」「触れてほしい場所への誘導」など、実践できるスキンシップミッション
- **チェックボックスによる自由なデッキ選択**:
  - 「Level 1」「Level 2」「Level 3」「スキンシップ」を自由に組み合わせて山札を生成可能
  - 「スキンシップカード単体」「Level 2 ＋ スキンシップのみ」など、シチュエーションに合わせて思い通りの山札で遊べます
- **リアルな心理対話を促す工夫**:
  - 直感的にテンポよく本音が言える「YES / NO」質問や「A or B」2択質問を導入
- **Night Romantic テーマ & iOS Safari 完全対応**:
  - 深みのあるワインレッド、インディゴ、シャンパンゴールドを基調とした上質なビジュアル
  - スムーズな 3D カードめくりアニメーション（iPhoneでも裏面の文字が透けない完全対策済み）
- **安心のセーフティ機能 & 進行サポート**:
  - **パス（スキップ）機能**: 答えたくない質問はペナルティなくワンタップでスキップ可能
  - **ターン表示**: 「あなたから回答」「パートナーが回答」「2人で答える」を案内
  - **3つの約束（HOW TO PLAY）**: パス自由・本音を否定しない・2人だけの秘密
- **カスタマイズ & お気に入り**:
  - **オリジナルカード作成**: 2人だけの特別な質問やアクションを追加・編集可能（ブラウザの LocalStorage に保存）
  - **お気に入り機能**: 後でまた話したい質問を保存・閲覧可能
- **サイレント設計**:
  - 2人の会話の空気感や囁きを遮らない無音仕様

## 🛠️ 技術スタック

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** (Night Romantic カスタムテーマ)
- **Lucide React** (アイコン)
- **Canvas Confetti** (演出)

---

## 🚀 起動方法

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

ブラウザで `http://localhost:5173/sekirara-nights/` を開いてご利用いただけます。

### 3. プロダクションビルド
```bash
npm run build
npm run preview
```
